# Application de Traitement d'Images 🖼️

Application Python avec interface graphique pour le traitement d'images, convertie depuis MATLAB (App Designer).

## Technologies utilisées

- **Python 3**
- **Tkinter** — interface graphique
- **OpenCV** — traitement d'images
- **NumPy** — calculs matriciels
- **SciPy** — filtres et convolutions
- **Pillow** — affichage des images

## Installation

```bash
pip install opencv-python numpy scipy pillow
```

## Lancement

```bash
python app1.py
```

## Fonctionnalités

### Opérations ponctuelles
- Contraste, Décalage additif, Mise à l'échelle, Inversion, Seuillage

### Bruit
- Bruit Gaussien, Bruit Poivre et Sel

### Filtres Fréquentiels (FFT)
- Passe-bas, Passe-haut, Passe-bande, Rehaussement des hautes fréquences

### Filtres Passe-bas spatiaux
- Moyenneur 3×3 / 5×5, Gaussien 3×3 / 5×5, Pyramidal, Conique, Médian

### Détection de contours
- Gradient, Sobel, Prewitt, Robert, Laplacien, Canny, Kirsch, Marr-Hildreth

### Morphologie mathématique
- Érosion, Dilatation, Ouverture, Fermeture
